## Context

I wanted to get my hands on infrastructure outside of work, so I built a personal homelab to experiment with Kubernetes and self-hosted services.

## Hardware

Assembling the components (motherboard, power supply, storage) then installing a Linux system dedicated to the cluster.

## Software

- **K3S** as a lightweight Kubernetes distribution.
- **Docker** to package some of the services.
- **Grafana** for monitoring and dashboards.
- **UptimeKuma** for uptime monitoring.
- A self-hosted **Gitea** server for my personal repositories.

## What I learned

This project let me get hands-on with DevOps concepts (deployment, monitoring, networking) on infrastructure I control end to end, from the hardware up to the application services.
