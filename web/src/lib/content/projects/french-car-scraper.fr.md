## Contexte

Un petit outil pour récupérer automatiquement des informations sur un véhicule français à partir de sa plaque d'immatriculation.

## Fonctionnement

Le scraper utilise **Puppeteer** pour piloter un navigateur headless, aller chercher les informations publiques disponibles sur une plaque donnée, puis les restituer sous une forme exploitable.

## Distribution

Le projet est packagé et publié en tant que **paquet NPM**, ce qui permet de l'intégrer facilement dans d'autres projets Node.js.

## Stack technique

- Node.js
- Puppeteer
- Publication sur le registre NPM
