## Context

A small tool to automatically retrieve information about a French vehicle from its licence plate number.

## How it works

The scraper uses **Puppeteer** to drive a headless browser, fetch the public information available for a given plate, then return it in a usable format.

## Distribution

The project is packaged and published as an **NPM package**, making it easy to integrate into other Node.js projects.

## Tech stack

- Node.js
- Puppeteer
- Published on the NPM registry
