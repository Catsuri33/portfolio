## Context

Omni is a school project built with 15 other students. The goal is to create a self-hostable, sovereign collaborative suite similar to Proton or Google Workspace, which we aim to make open source.

## Features

- A centralized authentication system
- A drive
- A password manager
- A video conferencing tool
- An admin panel to manage the suite
