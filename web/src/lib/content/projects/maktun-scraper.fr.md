## Contexte

Un outil de scraping pour cataloguer automatiquement une collection de pièces de monnaie.

## Fonctionnement

À l'aide de **Puppeteer**, le script parcourt les pages listant les pièces d'une collection et en extrait les informations utiles : nombre de pièces, noms, descriptions et années d'émission.

## Stack technique

- Node.js
- Puppeteer
